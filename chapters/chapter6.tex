\section{Chain Conditions (Complete)}

\subsection{Exercise}\label{6.1}

\begin{proof}
(i) $u : M \to M$ is a surjective module homomorphism. Then, $\ker u$ is a submodule of $M$. In fact, we have an ascending chain of submodules
$\ker u \subset \ker u^2 \subset \cdots \subset \ker u^n \subset \cdots$. Since $M$ is a Noetherian $A$-module, this chain becomes
stationary so that $\ker u^n = \ker u^{n+1}$ for some $n > 0$. Since $u$ is surjective, $u^n$ is surjective, so every $m \in M$ is of 
the form $m = u^n(m')$ for some $m' \in M$. If $m \neq 0$, $m' \not\in \ker u^n = \ker u^{n+1}$. Thus, $u(m) = u^{n+1}(m') \neq 0$, so 
$m \not\in \ker u$. Thus, $\ker u = 0$, so $u$ is an isomorphism.

(ii) $u : M \to M$ is an injective module homomorphism. Then, $\im u$ is a submodule of $M$. We have a descending chain of submodules 
$\im(u) \supset \im(u^2) \supset \cdots$. Since $M$ is an Artinian $A$-module, this chain becomes stationary so that $\im u^n = \im u^{n+1}$
for some $n > 0$. Since $u$ is injective, $u^n$ is injective for all $n > 0$. Let $m \in M$. Then, $u^n(m) \in \im u^n = \im u^{n+1}$, so
there is some $m' \in M$ such that $u^{n+1}(m') = u^n(m)$. Since $u^n$ is injective, $u^n(m) = u^n(u(m'))$ implies that $m = u(m')$. Thus,
$m \in \im u$ so that $\im u = M$. Hence, $u$ is an isomorphism.
\end{proof}

\subsection{Exercise}\label{6.2}

\begin{proof}
Let $N$ be an arbitrary submodule of $M$. Let $\Sigma$ be the set of finitely generated submodules of $N$. This is a non-empty set of finitely
generated submodules of $M$, so by assumption, it has a maximal element $N_0$. $N_0$ is finitely generated and $N_0 \subset N$. Suppose $x \in N$.
Then, $N_0 + Ax \subset N$ and $N_0 + Ax$ is a finitely generated submodule, so $N_0 + Ax \in \Sigma$. Since $N_0$ is maximal and 
$N_0 \subset N_0 + Ax$, we must have $x \in N_0$. Thus, $N = N_0$ so that $N$ is finitely generated. By Proposition 6.2, since every submodule
of $M$ is finitely generated, $M$ is Noetherian.
\end{proof}

\subsection{Exercise}\label{6.3}

\begin{proof}
Since $M/N_1$ and $M/N_2$ are both Noetherian (resp. Artinian), $M/N_1 \oplus M/N_2$ is Noetherian (resp. Artinian) via Corollary 6.4.
We have a module homomorphism $\varphi : M / (N_1 \cap N_2) \to M/N_1 \oplus M/N_2$ since $M / (N_1 \cap N_2) \to M/N_1$ and 
$M / (N_1 \cap N_2) \to M/N_2$ are both well-defined homomorphisms. Suppose $\varphi(m) = 0$. Then, $m \in N_1$ and $m \in N_2$, so 
$m \in N_1 \cap N_2$. Hence, $m = 0$, so $\varphi$ is injective. Thus, we have a short exact sequence of $A$-modules
$$0 \to M / (N_1 \cap N_2) \xlongrightarrow{\varphi} M/N_1 \oplus M/N_2 \to Q \to 0,$$
where $Q$ is the quotient module. By Proposition 6.3, since $M/N_1 \oplus M/N_2$ is Noetherian (resp. Artinian), $M / (N_1 \cap N_2)$
is Noetherian (resp. Artinian).
\end{proof}

\subsection{Exercise}\label{6.4}

\begin{proof}
Since $M$ is a Noetherian $A$-module and $\mathfrak{a} = \Ann(M)$, $M$ is a faithful, Noetherian $A/\mathfrak{a}$-module since all 
$A/\mathfrak{a}$-submodules are $A$-submodules. Thus, to show that $A/\mathfrak{a}$ is Noetherian, it is sufficient to show that
whenever $M$ is a Noetherian $A$-module such that $\Ann(A) = 0$, then $A$ is a Noetherian ring.

Since $M$ is Noetherian, it is finitely generated by Proposition 6.2. Let $\{m_i\}_{i=1}^n$ be a finite generating set of $M$. Since $M$ is Noetherian
$M^n$ is Noetherian by Corollary 6.4. We have an $A$-module homomorphism $a \mapsto (a m_1, \ldots, a m_n) \subset M^n$. Suppose that $a \mapsto 0$ so that 
for any $m = a_1 m_1 + \cdots + a_n m_n \in M$, we have $a m = 0$. Since $\Ann(M) = 0$, $a = 0$, so the map is injective. Since there is an $A$-module injection
of $A$ into the Noetherian $A$-module $M^n$, $A$ is Noetherian by Proposition 6.3.
\end{proof}

\begin{remark}
Note that this does not hold when we replace ``Noetherian'' with ``Artinian''. Consider the Pr\"ufer $p$-group $\Z/p^{\infty}\Z$, which is an 
Artinian $\Z$-module. If $a \in \Ann(\Z/p^{\infty}\Z)$, then $a \cdot 1 \in (p)^n$ for all $n > 0$. Clearly then, $a = 0$. However, $\Z/(0) \cong \Z$ 
is not Artinian since $(p) \supset (p^2) \supset \cdots$ is an infinite, strictly descending chain of ideals of $\Z$.
\end{remark}

\subsection{Exercise}\label{6.5}

\begin{proof}
Let $S$ be a subspace of $X$, and suppose we have a descending chain of closed sets $C_1 \supset C_2 \supset \cdots$ of $S$. Then,
$C_i = S \cap C_i'$, where $C_i'$ is a closed set of $X$. Let $K_i = \bigcap_{j \le i} C_j'$, a closed set of $X$. Clearly, $(K_i)_i$
forms a descending chain of closed sets of $X$. Since $X$ is Noetherian with respect to the open sets, $X$ is Artinian with respect 
to the closed sets, so there is some $n > 0$ such that $K_k = K_{k+1}$ for all $k \ge n$.

So, let $k \ge n$. Then, 
$$C_k = S \cap C_k' = S \cap \bigcap_{i \le k} C_i' = S \cap K_k = S \cap K_{k+1} = S \cap \bigcap_{i \le k+1} C_i' = S \cap C_{k+1}' = C_{k+1},$$
so $(C_i)_i$ stabilizes. Thus, $S$ is Artinian with respect to closed sets, so $S$ is Noetherian with respect to open sets, as desired.

Finally, suppose $\{U\}$ is an open cover of $X$. If the cover is finite, it is itself a finite subcover, so suppose $\{U\}$ is infinite.
Then, let $U_1 \in \{U\}$. If $x \in X - U_1$, there is some $U_2 \in \{U\}$ such that $x \in U_2$. Let $V_2 = U_2 \cup U_1$.
If there is some $x \in X - V_2$, there is some $U_3 \in \{U\}$ such that $x \in U_3$. Define $V_3 = U_3 \cup V_2$. If we can continue this process 
indefinitely, then we have a strictly ascending chain of open sets $V_1 \subset V_2 \subset \cdots$ of $X$. Since $X$ is Noetherian, this cannot happen.
Thus, for some $n > 0$, $V_n = X$ so that $\bigcup_{i=1}^n U_n = X$. Thus, $\{U\}$ has a finite subcover, so $X$ is quasi-compact.
\end{proof}

\subsection{Exercise}\label{6.6}

\begin{proof}
(i) $\implies$ (iii). If $X$ is Noetherian and $S$ is a subspace, then by Exercise \ref{6.5}, $S$ is a Noetherian space. Then, also by Exercise \ref{6.5},
$S$ is quasi-compact.

(iii) $\implies$ (ii). Clear. All open subspaces are subspaces.

(ii) $\implies$ (i). Let $U_1 \subset U_2 \subset \cdots$ be an ascending chain of open sets of $X$. Then, $S = \bigcup_i U_i$ is an open set, so by
assumption, the open subspace $S$ is quasi-compact. Note that $\{U_i\}$ is an open covering of $S$, so there is a finite subcover $\{U_i\}_{i \in I}$.
Thus, $I$ has a maximum index $n > 0$, so $S = \bigcup_{i \in I} U_i = U_n$ since $U_i \subset U_n$ for all $i \le n$. Thus, $U_n = \bigcup_i U_i \supset U_j$
for all $j$. Since $U_n \subset U_j$ for all $j \ge n$, $U_n = U_j$ for all $j \ge n$, so the chain stabilizes. Thus, $X$ is a Noetherian space.
\end{proof}

\subsection{Exercise}\label{6.7}

\begin{proof}
Let $\Sigma$ be the set of closed subsets of $X$ that are not finite unions of irreducible closed subspaces. Suppose to the contrary that $X$
is not a finite union of irreducible closed subspaces so that $X \in \Sigma$, i.e. $\Sigma$ is non-empty. Order $\Sigma$ such that $C \le C'$
if $C \subset C'$. Let $\mathcal{T}$ be a chain of $\Sigma$. Let $C_0 \in \mathcal{T}$. Then, we have a descending chain $\cdots \subset C_1 \subset C_0$ 
of closed subsets of $X$. Since $X$ is Noetherian, the set of closed sets of $X$ is Artinian, so there is some $n > 0$ such that $C_{j+1} = C_j$ for all 
$j \ge n$. Thus, $C_n$ is a minimal element of $\mathcal{T}$. By Zorn's lemma, $\Sigma$ has minimal elements.

Let $C$ be a minimal element of $\Sigma$. $C$ is non-empty since $\emptyset \not\in \Sigma$; $\emptyset$ is the empty union of irreducible closed subspaces.
So, let $x \in C$ and let $C_x$ be the closure of $\{x\}$. If $C$ were irreducible, then $C$ is just a finite union of closed irreducible closed subspaces
since it is itself a closed irreducible subspace. Therefore, $C$ is reducible so that $C = C_1 \cup C_2$, where $C_1$ and $C_2$ are closed subsets and 
$C_1 \neq C$ and $C_2 \neq C$. By the minimality of $C$, $C_1$ and $C_2$ are finite unions of irreducible closed subspaces. But then, $C = C_1 \cup C_2$
is a finite union of irreducible closed subspaces, yielding our desired contradiction. Thus, $X$ is a finite union of irreducible closed subspaces.

By Exercise \ref{1.20}, the maximal irreducible subspaces of $X$ are closed and cover $X$; these are the ``irreducible components''. Since $X$ is a finite
union of irreducible closed subspaces and each irreducible subspace is contained in a maximal irreducible subset by definition, $X$ is covered by finitely 
many irreducible components $\{C_i\}$. Let $Y$ be any irreducible component, so it is closed. Then,
$$Y = Y \cap X = Y \cap (C_1 \cup \cdots \cup C_n) = (Y \cap C_1) \cup \cdots \cup (Y \cap C_n),$$
a union of closed sets. By the irreducibility of $Y$, we must have $Y = Y \cap C_i$ for some $i$, so $Y \subset C_i$. Since $Y$ is maximal,
we must have $Y = C_i$. Hence, $X$ has finitely many irreducible components.
\end{proof}

\subsection{Exercise}\label{6.8}

\begin{proof}
Closed sets of $\Spec(A)$ are of the form $V(\mathfrak{a})$, where $\mathfrak{a}$ is an ideal of $A$. Thus, a descending chain of closed ideals of $\Spec(A)$
has the form $V(\mathfrak{a}_1) \supset V(\mathfrak{a}_2) \supset \cdots$. Note that $V(\mathfrak{a}_i) = V(r(\mathfrak{a}_i))$ and $r(\mathfrak{a}_i)$ is the
intersection of prime ideals containing $\mathfrak{a}_i$. Then, since $V(r(\mathfrak{a}_i)) \supset V(r(\mathfrak{a}_{i+1}))$, we have $r(\mathfrak{a}_i) \subset r(\mathfrak{a}_{i+1})$
since all the primes in the intersection of $r(\mathfrak{a}_{i+1})$ are in the intersection of $r(\mathfrak{a}_i)$. Therefore, we have an ascending chain
of ideals $r(\mathfrak{a}_1) \subset r(\mathfrak{a}_2) \subset \cdots$. Since $A$ is Noetherian, this chain stabilizes so that $r(\mathfrak{a}_i) = r(\mathfrak{a}_n)$
for all $i \ge n$ for some $n > 0$. Then, $V(\mathfrak{a}_i) = V(r(\mathfrak{a}_i)) = V(r(\mathfrak{a}_n)) = V(\mathfrak{a}_n)$, so the chain of closed sets also
stabilizes. Thus, $\Spec(A)$ is a Noetherian topological space.
\end{proof}

The converse is not true in general. Let $A = k[x_1,x_2,\ldots]/(x_1^2,x_2^2,\ldots)$. In $A$, each $x_i$ is nilpotent, so every prime ideal of $A$ contains each $x_i$.
Thus, any prime $\mathfrak{p}$ contains $(x_1,x_2,\ldots)$. If $a \in \mathfrak{p}$ such that $a \not\in (x_1,x_2,\ldots)$, then $a = l + f$, where $f \in (x_1,x_2,\ldots)$ 
and $l \in k^{\times}$. Then, $a,f \in \mathfrak{p}$ so that $l \in \mathfrak{p}$. But, $l^{-1} \in A$, so $1 = l^{-1}l \in \mathfrak{p}$, a contradiction. Thus,
there is only one prime $\mathfrak{p}$ and $\mathfrak{p} = (x_1,x_2,\ldots)$. Since $\Spec(A)$ is a singleton, it is clearly a Noetherian topological space.
However, $(x_1) \subset (x_1,x_2) \subset (x_1,x_2,x_3) \subset \cdots$ is an infinite, strictly ascending chain of ideals of $A$, so $A$ is not Noetherian,
even though $\Spec(A)$ is a Noetherian space.

\subsection{Exercise}\label{6.9}

\begin{proof}
Since $A$ is Noetherian, $\Spec(A)$ is a Noetherian topological space by Exercise \ref{6.8}. Then, by Exercise \ref{6.7}, $\Spec(A)$ has finitely many 
irreducible components. By Exercise \ref{1.20}, the irreducible components of $\Spec(A)$ are the closed sets $V(\mathfrak{p})$, where $\mathfrak{p}$ is a 
minimal prime ideal of $A$. Thus, there are only finitely many closed sets of $\Spec(A)$ of the form $V(\mathfrak{p})$, where $\mathfrak{p}$ is a minimal
prime ideal. If $V(\mathfrak{p}) = V(\mathfrak{q})$, then $\mathfrak{p}$ and $\mathfrak{q}$ are in both sets, so $\mathfrak{p} \subset \mathfrak{q}$ and
vice-versa so that $\mathfrak{p} = \mathfrak{q}$. Thus, the mapping from minimal primes of $A$ to closed sets, $\mathfrak{p} \mapsto V(\mathfrak{p})$, is
injective, so $A$ has finitely many minimal prime ideals.
\end{proof}

\subsection{Exercise}\label{6.10}

\begin{proof}
Since $M$ is a Noetherian $A$-module, it is finitely generated by Proposition 6.2. Then, by Exercise \ref{3.19}, $\Supp(M) = V(\Ann(M))$. Thus,
$\Supp(M)$ is a closed subspace of $\Spec(A)$. By Exercise \ref{6.4}, $A/\Ann(M)$ is a Noetherian ring since $M$ is Noetherian. By Exercise \ref{6.8},
$\Spec(A/\Ann(M))$ is a Noetherian space. Via the surjective ring homomorphism $\phi : A \to A/\Ann(M)$, we have a homeomorphism of $\Spec(A/\Ann(M))$
onto $V(\Ann(M))$ (Exercise \ref{1.21}). Hence, $\Supp(M) = V(\Ann(M))$ is Noetherian since it is homeomorphic to the Noetherian space $\Spec(A/\Ann(M))$.
\end{proof}

\subsection{Exercise}\label{6.11}

\begin{proof}
$f : A \to B$ is a ring homomorphism, and $\Spec(B)$ is a Noetherian space. If $f^* : \Spec(B) \to \Spec(A)$ is a closed mapping, then by
Exercise \ref{5.10}, $f$ has the going-up property. Conversely, suppose $f$ has the going-up property. To show that $f^*$ is a closed mapping, 
we must show that for any radical ideal $\mathfrak{b}$ of $B$, $f^*(V(\mathfrak{b}))$ is closed. 

We start with a prime ideal $\mathfrak{q}$ of $B$. By Exercise \ref{1.21}, $overline{f^*(V(\mathfrak{q}))} = V(\mathfrak{q}^c)$.
To show that $f^*(V(\mathfrak{q}))$ is closed, it is then sufficient to show that $f^*(V(\mathfrak{q})) = V(\mathfrak{q}^c)$. We have, by
the same exercise, that $f^*(V(\mathfrak{q})) \subset V(\mathfrak{q}^c)$, so suppose $\mathfrak{p}' \in V(\mathfrak{q}^c)$. Note that 
$\mathfrak{p} = \mathfrak{q}^c$ is a prime ideal of $A$, so we have $\mathfrak{q}^c = \mathfrak{p}$ and $\mathfrak{p}' \supset \mathfrak{p}$. 
By the going-up property, there is some prime ideal $\mathfrak{q}'$ of $B$ such that $\mathfrak{q}' \supset \mathfrak{q}$ and 
$\mathfrak{p}' = \mathfrak{q}'^c$. Thus, $\mathfrak{q}' \in V(\mathfrak{q})$, so $\mathfrak{p}' = f^*(\mathfrak{q}') \in f^*(V(\mathfrak{q}))$. 
For any prime ideal $\mathfrak{q}$ of $B$, we thus have $f^*(V(\mathfrak{q})) = V(\mathfrak{q}^c)$.

Now, let $\mathfrak{b}$ be an arbitrary radical ideal of $B$, so $\mathfrak{b} = \bigcap_{\mathfrak{q} \in V(\mathfrak{b})}\mathfrak{q}$. Since $\Spec(B)$
is Noetherian, $V(\mathfrak{b})$ is Noetherian by Exercise \ref{6.5}. By Exercise \ref{1.21}, $V(\mathfrak{b})$ is homeomorphic to $\Spec(B/\mathfrak{b})$,
so $\Spec(B/\mathfrak{b})$ is Noetherian. Thus, $\Spec(B/\mathfrak{b})$ has finitely many irreducible components by Exercise \ref{6.7}. 
By Exercise \ref{1.20}, the irreducible components of $\Spec(B/\mathfrak{b})$ are the closed sets $V(\mathfrak{p})$, where $\mathfrak{p}$ is a 
minimal prime ideal of $B/\mathfrak{b}$; hence $B/\mathfrak{b}$ has finitely many minimal prime ideals. By the one-to-one, order-preserving correspondence
between prime ideals of $B/\mathfrak{b}$ and primes of $B$ containing $\mathfrak{b}$, the set of primes of $B$ containing $\mathfrak{b}$ has finitely
many minimal elements $\{q_i\}$. Thus, we can write $\mathfrak{b} = \bigcap_{\mathfrak{q} \in V(\mathfrak{b})}\mathfrak{q} = \bigcap_{i=1}^n\mathfrak{q}_i$.

Finally, by Exercise \ref{1.15}, since the intersection is finite,
$$V(\mathfrak{b}) = V\left(\bigcap_{i=1}^n\mathfrak{q}_i\right) = \bigcup_{i=1}^n V(\mathfrak{q}_i)$$
so that
$$f^*(V(\mathfrak{b})) = f^*\left(\bigcup_{i=1}^n V(\mathfrak{q}_i)\right) = \bigcup_{i=1}^nf^*\left(V(\mathfrak{q}_i)\right) 
= \bigcup_{i=1}^n V(\mathfrak{q}_i^c),$$
which is closed since it is a finite union of closed sets. Thus, $f^*$ is a closed mapping, as desired.
\end{proof}

\subsection{Exercise}\label{6.12}

\begin{proof}
Let $\mathfrak{p}_1 \subset \mathfrak{p}_2 \subset \cdots$ be an ascending chain of prime ideals of $A$. Then, we have a descending chain of closed
sets $V(\mathfrak{p}_1) \supset V(\mathfrak{p}_2) \supset \cdots$. Since $\Spec(A)$ is Noetherian, we must have $V(\mathfrak{p}_n) = V(\mathfrak{p}_i)$
for all $i \ge n$ for some $n > 0$. But then, $\mathfrak{p}_n \in V(\mathfrak{p}_i)$, so $\mathfrak{p}_n \supset \mathfrak{p}_i$. Thus, for all
$i \ge n$, $\mathfrak{p}_n = \mathfrak{p}_i$. Therefore, the set of prime ideals of $A$ satisfies the ascending chain condition.
\end{proof}

The converse does not hold in general. Let $A = \prod_{i=1}^{\infty} K$, where $K$ is a field. Then, we have ideals of $A$ of the form $\prod_{i=1}^{\infty} I_i$, 
where $I_i$ is $0$ or $K$. Suppose $I$ is an ideal such that the $i$th factor is $0$, the rest being $K$. If $xy \in I$, then $x_i y_i = 0$, so either $x_i = 0$ or 
$y_i = 0$ since $K$ is an integral domain. Thus, $x \in I$ or $y \in I$, so $I$ is a prime ideal. We denote this prime ideal by $\mathfrak{p}_i$.

Let $\mathfrak{p}$ be an arbitrary prime ideal of $A$. For every $x = (x_1,x_2,\ldots) \in A$, we can define a ``pseudo-inverse'' by letting $y_i = x_i^{-1}$
if $x_i \neq 0$ and $y_i = 0$ if $x_i = 0$; let $y = (y_1,y_2,\ldots)$. Then, $(xy)_i = 1$ if $x_i \neq 0$ and $(xy)_i = 0$ if $x_i = 0$. Then, 
$(x^2y)_i = x_i$ if $x_i \neq 0$ and $(x^2y)_i = 0$ if $x_i = 0$. Thus, for all $i$, $(x^2y)_i = x_i$, so $x^2 y = x$. Now, let $\overline{x}$ be
an arbitrary element of $A/\mathfrak{p}$. Then, if $x \in A$ is a lift of $\overline{x}$, $x$ has a pseudo-inverse $y \in A$, so 
$\overline{x}^2\overline{y} = \overline{x}$. If $\overline{x} \neq 0$, then since $A/\mathfrak{p}$ is an integral domain, $\overline{x}\overline{y} = 1$,
so $A/\mathfrak{p}$ is a field. Thus, every prime ideal of $A$ is maximal, so no two distinct primes of $A$ are comparable. Therefore, the prime
ideals of $A$ satisfy the ascending chain condition trivially.

Let $I_i$ be the ideal such that the first $i$ factors are $K$ and the remaining factors are $0$. Then, $V(I_n) \supset \{\mathfrak{p}_{n+1},\mathfrak{p}_{n+2},\ldots\}$
and $\mathfrak{p}_n \not\in V(I_n)$. Thus, we have an infinite, descending chain of closed sets $V(I_1) \supset V(I_2) \supset \cdots$. Note that all inclusions are strict 
since for all $n$, $\mathfrak{p}_{n+1} \in V(I_n) - V(I_{n+1})$, so the closed sets do not satisfy the descending chain condition. Thus, $\Spec(A)$ is not Noetherian.
